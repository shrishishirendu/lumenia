B) STRUCTURED SESSION FLOW v1
Route: /student/session/:subject/:topic (or similar)

Session must be a guided sequence with steps:

Step 1: Warmup Quiz (2–4 Qs)
- Generate questions based on:
  - last session mistakes for this subject, OR
  - weakest topic in mastery map
- Show immediate feedback + hint
- Capture attempt data

Step 2: Micro Lesson (3–5 mins)
- One concept explanation + 1 worked example
- Provide “Explain differently” button (visual / analogy / step-by-step)
- Capture if student requested alternate explanation

Step 3: Practice Set (adaptive)
- Start easy → medium → challenge
- After each question, update difficulty based on correctness and hints
- Allow scratchpad/workspace if already exists
- Capture attempts, hints, time-on-task

Step 4: Reflection
- 2 quick prompts:
  - “What was the key idea?”
  - “Where did you feel stuck?”
- Save reflection text

Step 5: Exit Ticket (1–2 Qs)
- Must test the same concept
- If failed, recommend “Mini-review” and do NOT mark mastered

Step 6: Next Step
- Show:
  - what improved
  - what to do next
  - suggested next topic
  - optional “Homework: 3 questions” (can be generated and stored)

Session End must generate a compact “Session Summary” for student view:
- score, time, hints used, outcome (mastered / practicing / needs help)

C) MASTERY TRACKING (CORE)
Implement a simple Mastery Map per student per subject:
Statuses:
- not_started
- learning
- practiced
- mastered

Store for each topic:
- masteryStatus
- lastSeenAt
- accuracyRolling (e.g., last 10 attempts)
- commonMistakes tags (simple strings)
