5) CONTENT SCOPE (Cambridge-style)

This chapter covers:
- Gradient (slope) of a line from two points
- Gradient from equation y = mx + c
- Parallel lines have equal gradients
- Perpendicular lines (optional challenge only): m1*m2 = -1 (only if you want)
- Recognising parallel lines from a simple diagram or coordinate grid (visual questions)

Avoid full coordinate geometry proofs; keep it skill-based.

6) ARCHETYPES & DIFFICULTY BANDS

EASY (8)
Archetypes:
- slope_from_points_easy: Find gradient between two integer points (small values)
- slope_from_equation_easy: Identify m from y = mx + c
Constraints:
- Use gradients like -3, -2, -1, 0, 1, 2, 3, 1/2, 2/3
Answer format:
- Return as integer or simplified fraction string (e.g., "-3/2")
Skills tags:
- ["gradient_from_points", "gradient_from_equation"]

MEDIUM (8)
Archetypes:
- parallel_from_equations: Decide if two lines are parallel given their equations
- find_missing_m_for_parallel: Find k so that y = kx + b is parallel to y = mx + c
- slope_from_table: Provide two points in a small table, compute gradient
Constraints:
- Simplified fractions required
Skills tags:
- ["parallel_lines", "compare_gradients", "solve_for_parameter"]

HARD (7)
Archetypes:
- equation_given_point_and_gradient: Find equation y = mx + c given m and one point
- parallel_through_point: Find equation of line parallel to given line passing through a given point
- identify_parallel_in_set: Given 3–4 line equations, select which are parallel
Constraints:
- Keep c integer when possible; allow simple fraction m
Skills tags:
- ["line_equation", "parallel_lines", "solve_for_c", "select_parallel"]

CHALLENGE (7)
Archetypes:
- perpendicular_optional: Find gradient or equation of perpendicular line through a point (only in challenge)
- multi_step_parallel: Given two points on a line and a point to pass through, create a parallel line equation
- visual_parallel_reasoning: Use a diagram with parallel lines to infer equal gradients or missing value
Skills tags:
- ["multi_step", "parallel_lines", "perpendicular_lines", "interpret_diagram"]
