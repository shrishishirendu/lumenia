5) CONTENT SCOPE: FINDING EQUATIONS OF LINES

Students should learn to find an equation in the form y = mx + c from:
- Given m and c directly
- Given two points
- Given gradient and one point
- Given a point and a parallel line (same gradient)
- Given a point and a perpendicular line (optional challenge)

Also include reading info from a graph/diagram for visual questions.

6) ARCHETYPES & DIFFICULTY BANDS (Cambridge-style)

EASY (8)
Archetypes:
- from_m_and_c: given m and c, write equation
- from_graph_y_intercept: given y-intercept and gradient as integers (no fractions)
Constraints:
- m in {-3,-2,-1,0,1,2,3}
- c in [-8..8]
Skills tags:
- ["slope_intercept_form", "identify_m", "identify_c"]

MEDIUM (8)
Archetypes:
- from_two_points: find m using (y2-y1)/(x2-x1), then find c
- from_point_and_gradient: given point (x1,y1) and m, solve for c
- parallel_through_point: parallel to y=mx+c through point
Constraints:
- Use simple fractions for m sometimes (e.g., 1/2, -2/3)
- Keep c as integer or simple fraction if unavoidable
Skills tags:
- ["gradient_from_points", "solve_for_c", "parallel_lines", "line_equation"]

HARD (7)
Archetypes:
- two_points_fractional_slope: two points that yield fractional slope
- parallel_and_intercept: given a line and x-intercept/y-intercept constraints (keep manageable)
- choose_correct_equation: give 3 candidate equations; pick which matches given point + gradient (autogradable as option selection if supported)
Constraints:
- Ensure final equation can be expressed cleanly in y=mx+c
Skills tags:
- ["fraction_slope", "rearrange_to_slope_intercept", "multi_step"]

CHALLENGE (7)
Archetypes:
- perpendicular_optional: line perpendicular to given line through a point (m_perp = -1/m)
- visual_from_graph: read two points from a drawn line, then find equation
- mixed_constraints: line passes through two points and is parallel to another (redundant check)
Constraints:
- Include at least 2 visual questions in challenge
Skills tags:
- ["perpendicular_lines", "interpret_graph", "multi_step_reasoning"]

9) ANSWER CHECKING (IMPORTANT)

Do NOT rely only on strict string equality for line equations.

Implement an equivalence check WITHOUT heavy dependencies:
- Parse both expected and student equation into a function f(x) for multiple x values OR convert to a standard form.
Minimum approach:
- Force canonical form acceptance: accept answers only in y=mx+c and parse m and c from normalized input.
Better approach (recommended):
- Evaluate equivalence at 4-6 x values (e.g., x in [-2,-1,0,1,2,3]) and compare y outputs.
- For student equations not in slope-intercept, attempt to rearrange OR reject with feedback “Please give answer as y = mx + c”.

Pick one approach and implement consistently across this topic.

Safety:
- Use a safe evaluator or a restricted parser:
  numbers, x, y, +, -, *, /, ^, parentheses, '='
- Do not allow arbitrary code execution.
